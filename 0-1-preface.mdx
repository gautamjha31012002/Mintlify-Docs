You already operate complex system for living. You know how to reason about a failing pod, trace a request through five hops of network, write a Terraform module that does not make your colleagues wince, and sleep (lightly) through an on-call shift. What you may not know is how to put a large language model (LLM) to work as a dependable member of that system — not a chatbot, not a demo, but a component that plans, calls your tools, execute real operations, checks it's own work and ask for help when it should.

That is what this Docs teaches, and it teaches it in Go.
